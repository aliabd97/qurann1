# خارطة التنقل الداخلي (Navigation Map) - مشروع القرآن الكريم الكافي

يتناول هذا المستند النماذج والمتحولات ومسارات التنقل الحالية داخل كود Kotlin والهيكل التفاعلي لتقنية Jetpack Compose، وكيفية مزامنتها بسلاسة لتسيير الانتقال دون أي ضياع في بيئة Flutter القادمة.

---

## 1. نموذج حالات التنقل في الواجهة العليا (`Root Navigation States`)

في النموذج الحالي للتطبيق (كما هو مبسط ومقعد بقوة في كلاس `MainActivity.kt`)، تدار خريطة التنقل بالكامل بالاستعانة بمصفوفة متحولات حالة تفاعلية بسيطة وواضحة (بدون الاستعانة بكود توجيه معقد كـ Router خارجي، ليسهل تحويلها في Flutter إما باستخدام Navigator 1.0 أو Navigator 2.0 أو حزمة GoRouter التوعوية).

فيما يلي مصفوفة المتغيرات التي تتحكم بمسار التنقل عبر الشاشات وتوقيعاتها البرمجية:

* **`activeTab`** (`var activeTab by remember { mutableStateOf("home") }`):
  تتحكم بالتبويب الفعال بأسفل الشاشة ويقبل ثلاث قيم أساسية:
  * `"home"`: تفتتح الشاشة الرئيسية الكلية ومحركات البحث السريع.
  * `"quran"`: شاشة تصفح وقراءة القرآن الكريم (وتتفرع ديناميكياً لمعالج القراءة بالتناوب: `StudyReaderScreen` أو `MushafReaderScreen` تبعاً لقراءة حالة `viewModel.readingMode`).
  * `"packages"`: شاشة إدارة وتثبيت حزم الكتب والتفاسير الصوتية دون إنترنت.

* **`currentScreen`** (`var currentScreen by remember { mutableStateOf("main") }`):
  تحدد السفر الطولي للشاشات الكبرى (على شكل طبقات Stack):
  * `"main"`: عرض الحاضنة التبويبية الاعتيادية مع الشريط السفلي (NavigationBar).
  * `"details"`: تفتح الشاشة الفائقة للتبيان المفصل للآية الممنوحة (`AyahDetailsScreen` والتبويبات الخمسة) مع حجب الشريط السفلي لضمان طمأنينة وتركيز مع الدارس.

* **`showSurahIndex`** (`var showSurahIndex by remember { mutableStateOf(false) }`):
  * علم ثنائي (Boolean): عند تفعيله كـ `true` تُحجب كافة الشاشات الخلفية وتبرز شاشة الفهرس الكلي للمستخدم (`SurahIndexScreen`). وعند اختيار سورة، يعاد تصفير العلم وتصفية المحتوى.

* **`selectedAyahForDetails`** (`var selectedAyahForDetails by remember { mutableStateOf<AyahEntity?>(null) }`):
  * يحقن فيه كيان الآية الحالية ليكون مرجعاً للبيانات والشروحات في شاشة التفاصيل الكلية.

* **`initialDetailsTab`** (`var initialDetailsTab by remember { mutableStateOf(0) }`):
  * رقم صحيح يحدد تبويب شاشة التفاصيل المستهدف مباشرة عند الافتتاح (مثال: إذا نقر المستخدم على "إعراب الآية" من ورقة الخيارات، يوجه لـ `details` وتكون الصفحة رقم 1 هي المفتوحة مباشرة للتسهيل).

## 2. المسارات التفاعلية ومخطط الانتقال (Navigation Sequence)

```
                       [ الشاشة الرئيسية - HomeScreen ]
                                      │
        ┌─────────────────────────────┼─────────────────────────────┐
        ▼                             ▼                             ▼
(نقرة بحث/فهرس)               (اختيار المكتبة)              (آية اليوم للتدبر)
        │                             │                             │
        ▼                             ▼                             ▼
 [ SurahIndexScreen ]        [ PackageManagerScreen ]      [ AyahDetailsScreen ]
        │                             │                             │
    (سفر فوري)                     (رجوع)                        (رجوع)
        │                             │                             │
        ▼                             ▼                             ▼
 [ القرآن: الدراسة ] ◄───────► [ القرآن: المصحف ] <─────────── (الرئيسية)
        │                             │
   (نقرة مطولة)                  (نقرة بسيطة)
        │                             │
        ▼                             ▼
                 [ AyahActionSheet (خيارات الآية) ]
                                 │
           ┌─────────────────────┴─────────────────────┐
           ▼                                           ▼
   (تبيان مفصل/إعراب)                            (كبسولة اللفظ)
           │                                           │
           ▼                                           ▼
  [ AyahDetailsScreen ]                      [ WordDetailsSheet ]
```

## 3. سيناريوهات التنقل البرمجية وتفاعلاتها الدقيقة (User Journeys)

### السيناريو الأول: التنقل من الشاشة الرئيسية إلى القارئ والبدء بسورة مختارة
1. يكتب المستخدم حروفا في حقل البحث بـ `HomeScreen` أو ينقر "فهرس السور".
2. تبرز قائمة السور، وعند الضغط على سورة تتبين هكذا: `viewModel.selectSurah(selectedSurahId)`.
3. تغلق شاشة الفهرس كلياً `showSurahIndex = false`.
4. ينتقل التبويب النشط فوراً لقارئ القرآن `activeTab = "quran"`.
5. يباشر كلاس الـ Pager بالتحرك للـ Surah المستهدفة وتظهر الآيات بالتنزيل والتشكيل ومكتملة الخصائص.

### السيناريو الثاني: التقدم من قارئ القرآن الكافي إلى تفصيل وبناء الإعراب للآية
1. يسحب تصفح الآيات بنمط الدراسة، فيعثر على آية ويقوم بالنقر عليها بنقرة مطولة.
2. تدرج ورقة الخيارات السفلى `AyahActionSheet` وبها أزرار تبيان مذهبة.
3. ينقر المستخدم على الزر "إعراب الآية".
4. ترسل الوراقة حدث المعالجة: `onOptionSelected("irab")`.
5. يقوم القارئ بتوجيه التبويب المستهدف في شاشة الإخوة بـ `initialDetailsTab = 1`.
6. يتم تثبيت الآية المرغوبة `selectedAyahForDetails = currentAyah` وحل الشاشة `currentScreen = "details"`.
7. تفتح واجهة التفاصيل مباشرة على تبويب الإعراب، ليطلع المستخدم لغوياً على الحروف ومواضع الجمل فطوراً.

### السيناريو الثالث: قراءة كلمة بكلمة والإطلاع على تفصيل لفظي في الدراسة
1. بنمط الدراسة، يعاين القارئ صف الكلمات المتراص تحت الآيات بوضوح.
2. تستثيره مفرّدة معينة، فيقوم بنقرها نقرة خفيفة.
3. يستقبل التطبيق التفاعل: `viewModel.selectWord(word)`.
4. ينبثق فورياً صندوق الـ `WordDetailsSheet` مروياً بجدول كلمات تلك الآية بالكامل لتسهيل الانزلاق والتناوب الحسي اليميني واليساري بيسر وعلمية.

### السيناريو الرابع: إدارة الحزم والمكتبة
1. ينقر المستخدم على تبويب "المكتبة والحزم" من شريط الواجهات الأساسي بالأسفل.
2. يتم تحريك المتحول الأساسي `activeTab = "packages"`.
3. يعرض نظام الخدمات الحزم الجاهزة (كتب تفسير أو تراجم لغوية) مع إمكانات "تحميل وتفعيل" أو "إيقاف تنشيط". عند إتمام العملية، يتم تحديث حالة `packages` بالـ ViewModel وتنعكس فلاتر شريط تخصيص العرف تلقائياً.
